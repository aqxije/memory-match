# 记忆翻牌（Memory Match）

一个**双击即玩、零依赖、零网络**的浏览器记忆翻牌配对小游戏，面向儿童（4–10 岁）：训练记忆力、专注力与耐心。
含 4 档难度、连击计分、1–3 星评定、本地排行榜与最高分持久化、WebAudio 合成音效、粒子与庆祝动画，支持鼠标 / 触屏 / 键盘全流程操作。

- 纯原生 HTML + CSS + JavaScript，**无构建、无第三方依赖、无 CDN、无图片/音频/字体文件**
- 逻辑核心为 UMD 双模式：浏览器挂 `window.MM.Core.*`，Node 可直接 `require`（自动化测试用）
- 双击 `index.html`（`file://`）即可完整游玩；也可用任意静态服务器打开

---

## 快速开始

### 方式一：双击打开（推荐，离线可用）

直接双击仓库根目录的 `index.html`，浏览器以 `file://` 打开即可游玩，无需安装任何东西、无需联网。

### 方式二：本地静态服务器（持久化更稳定）

```bash
# 在仓库根目录执行
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000/
```

`file://` 下部分浏览器/隐私模式会限制 `localStorage`，此时游戏会自动降级为「本次会话内有效」的内存排行榜（界面提示一次，不阻塞游玩）。若希望最高分稳定跨刷新保存，建议使用方式二。

## 游戏规则

1. 开局时所有卡片背面朝上；每局从 24 个 emoji 符号中随机抽取若干**互不相同**的符号，每个符号生成 2 张牌并随机洗牌。
2. 每次最多翻开 2 张牌：
   - 翻开第 1 张：不计步数；**本局第一次翻牌时开始计时**。
   - 翻开第 2 张：立即进入判定锁（LOCKED），步数 +1，随后判定。
3. 判定结果：
   - **符号相同** → 两张牌标记为已配对（此后不可再点），连击 +1，按计分规则加分，回到可翻牌状态。
   - **符号不同** → 连击归零、**不扣分**，两张牌保持可见 **800ms** 后自动翻回背面（期间点击被忽略）。
4. 判定锁期间的所有翻牌点击都被忽略（不排队、不缓冲）；点击已翻开或已配对的牌无任何状态变化。
5. 全部牌配对完成 → 进入结算：停止计时、评定星级、写入该难度排行榜。
6. 暂停 / 切到后台：计时冻结、输入屏蔽；恢复可见后**不会自动继续**，需点击「继续玩」。
7. 重开：同难度新局，局内分数/步数/用时/连击归零，排行榜与最佳分不变（重开需二次确认，防误触）。
8. 返回菜单 / 换难度：放弃当前局，**不写榜**。
9. 无倒计时、无生命值、无扣分、无失败弹窗；配对失败只表现为温和提示音 + 翻回。

## 计分与连击

- 每次配对成功的基础分为 **100 分**；连续成功配对（中间无失败）第 n 次得分为：

  ```
  得分 = 100 + 50 × min(n − 1, 4)
  ```

| 连击 n | 本次得分 | 累计 |
|---|---|---|
| 1 | 100 | 100 |
| 2 | 150 | 250 |
| 3 | 200 | 450 |
| 4 | 250 | 700 |
| 5 | 300 | 1000 |
| ≥6 | 300 | 每对 +300 |

- 配对失败：不得分、不扣分，连击归零。
- 暂停、切后台、点击已翻开的牌：**不打断连击**。
- 总分 = 各次配对得分之和；理论满分（全连击）见下表。

## 难度与星级

| 档位 | 名称 | 网格（列×行） | 牌数 | 对数 | 3★ 步数 ≤ | 2★ 步数 ≤ | 3★ 用时 ≤ | 2★ 用时 ≤ | 理论满分 |
|---|---|---|---|---|---|---|---|---|---|
| D1 | 简单 | 3×4 | 12 | 6 | 9 | 15 | 60s | 120s | 1300 |
| D2 | 普通 | 4×4 | 16 | 8 | 12 | 20 | 80s | 160s | 1900 |
| D3 | 困难 | 5×4 | 20 | 10 | 15 | 25 | 100s | 200s | 2500 |
| D4 | 挑战 | 6×6 | 36 | 18 | 27 | 45 | 180s | 360s | 4900 |

星级规则：

- 步数星：`moves ≤ ceil(pairs × 1.5)` → 3 星；`moves ≤ ceil(pairs × 2.5)` → 2 星；否则 1 星。
- 用时星：`timeMs ≤ pairs × 10s` → 3 星；`timeMs ≤ pairs × 20s` → 2 星；否则 1 星。
- 综合星级 = **min(步数星, 用时星)**，完成即至少 1 星（无 0 星、无失败态）。
- 用时只影响星级与排行榜排序，不产生任何失败或惩罚。

## 排行榜与存档

- 每个难度独立一个排行榜，保留 **Top 5**；单条记录字段：`{ score, moves, timeMs, stars, completedAt }`。
- 排序规则（严格按序）：`score` 降序 → `moves` 升序 → `timeMs` 升序 → `completedAt` 升序。
- 最佳分 = 该难度第 1 名分数（空榜为 0）；结算时本局分数**严格大于**写入前最佳分才显示「新纪录！」。
- 排行榜界面：4 个难度页签 + Top 5（名次/分数/步数/用时/星级/日期）；空榜显示鼓励文案；「清空记录」需二次确认，按当前页签清空。
- 存储键（`localStorage`，命名空间 `mm.v1.`）：
  - `mm.v1.leaderboard`：`{ version: 1, boards: { easy, normal, hard, challenge } }`
  - `mm.v1.settings`：`{ version: 1, muted, difficulty }`
- 健壮性：JSON 损坏 / 结构不符 / 版本不匹配 → 回退默认值；单条记录非法 → 丢弃该条；写入抛异常（配额/隐私模式）→ 降级内存态，游戏与结算照常，不崩溃、不弹错误框。
- 数据仅保存在本机浏览器，无埋点、无网络上传。

## 无障碍与儿童友好

- 键盘可完成「选难度 → 开局 → 翻牌 → 暂停 → 继续 → 重开 → 返回」全流程（`Tab` / `Shift+Tab` / `Enter` / `Space` / `Esc` / `M`）。
- 真实 `<button>` 卡片 + `aria-label` / `aria-pressed` / `aria-disabled`（不使用 `disabled`，保证 Tab 可达与朗读）；HUD 与关键事件通过 `role="status" aria-live="polite"` 播报（≥300ms 合并，保留最后一条，避免频繁打断）。
- 弹层焦点管理：暂停时背景棋盘设 `inert`（不可聚焦、移出无障碍树；不支持 `inert` 的浏览器回退为临时 `tabindex="-1"`），暂停面板内 `Tab` 焦点循环；结算与排行榜具 `role="dialog" aria-modal="true"` 语义；关闭确认弹层后焦点回到触发按钮。
- 排行榜难度页签为普通按钮组（`role="group"` + `aria-pressed` 表达选中），不使用不完整的 ARIA tabs 模式。
- 对比度：正文 ≥4.5:1、大字 ≥3:1、焦点 ≥3:1；正文 ≥16px、标题 ≥28px、圆角 ≥12px；马卡龙配色 ≥4 色；牌背「?」为深色（对比 6.57:1）。
- 系统开启「减少动效」（`prefers-reduced-motion: reduce`）时：关闭粒子、抖动与星星弹出，翻牌降级为即时切换；**规则与计时完全不受影响**。
- 无倒计时、无生命值、无扣分、无失败弹窗；文案全部鼓励性：错配时棋盘上方显示约 2s 的可见鼓励提示条（「再试一次～」「差一点点！」「没关系，记住它们」），低星结算显示鼓励语（如「慢慢来，你已经很棒了！」），并同步屏幕阅读器播报。
- 移动端：`viewport-fit=cover` + `env(safe-area-inset-*)` 适配刘海/圆角；360×640 竖屏下 D4（6×6）卡片约 53.0px ≥44px，无横向滚动；320×568 下约 46.8px ≥44px。

## 技术说明

- **零依赖、零构建、零网络**：无 `package.json`、无 `node_modules`、无打包器；不加载任何 CDN / Web Font / 图片 / 音频文件。图标全部用 emoji，音效全部由 WebAudio 振荡器 + 包络合成。
- **file:// 兼容**：不使用 ES module（`type="module"`）、`fetch`、动态 `import()`（`file://` 下会被 CORS 拦截）；`index.html` 末尾按依赖顺序加载经典 `<script>`，每个模块加载时断言依赖存在，`main.js` 启动时再次断言缺失模块并显示友好错误页（不白屏）。
- **逻辑 / 渲染分离**：`src/core/*` 不引用 `window` / `document` / `localStorage` / `navigator`；渲染层只消费冻结快照与事件，不反向定义逻辑。同一份 core 源码在 Node 与浏览器双模式运行。
- **可测试性**：时钟、随机源、存储、墙钟全部依赖注入（`timer / rng / storage / wallNow`），因此 39 条 `[L]` 类验收标准可在 Node 无 DOM 环境下断言。
- **性能**：渲染层零定时器（HUD 由逻辑层 `tick` 事件驱动）；动画只使用 `transform` / `opacity`；粒子单次 ≤12、同时存活 ≤120、结束自动移除；重开/换难度不重绑事件监听器（事件委托），逻辑定时器全部取消。
- **视觉与响应式**：卡片 3D 翻转由块级 `.card__inner` 驱动，牌背渐变/圆点纹理/深色「?」与正面 emoji（大卡附中文名）均按卡片尺寸渲染；布局统一由 `computeLayout` 计算（含棋盘 padding，360×640 与 320×568 无内部/页面横向滚动）；360px 竖屏排行榜压缩单元格内边距以完整显示日期；横屏/极矮视口（如 640×360）棋盘区域内部纵向滚动、HUD 与底部按钮固定、卡片保底 44px。
- **代码规模**：约 2953 行（HTML 187 + JS 2292 + CSS 474），单文件最大 500 行（`src/core/game.js`）。SPEC 原自设「≤1200 行」约束未达成，**经项目验收记录豁免**（理由：模块化良好、单文件 ≤500、零依赖，详见「已知限制」）。

## 已知限制

1. **代码规模偏差**：实际约 2953 行，超出规格自设的「源码总计 ≤1200 行」约束；单文件均 ≤500 行、零依赖、模块化分层清晰。该偏差**经项目验收记录豁免**。
2. **键盘方向键网格导航未实现**（架构文档中标为可选增强）：`Tab` / `Shift+Tab` / `Enter` / `Space` / `Esc` 全流程可用。
3. **未提供「清空全部难度」UI 入口**：界面按当前难度页签清空（符合规格裁决）；逻辑层已提供 `clearAllLeaderboards()` 接口。
4. **浏览器兼容性**：开发与自动化验证基于 Chrome 156（headless）；目标为 Chrome / Edge / Firefox 最近两个大版本、Safari 15+、Android Chrome 100+，但 **Safari / Firefox 真机未实测**。已做 3D 翻牌 `@supports` 回退、`webkitAudioContext` 前缀、安全区与 `dvh` 回退。
5. **横屏 / 极矮视口**（如 640×360）：为保证触控目标 ≥44px，卡片不再缩小，棋盘区域改为内部纵向滚动（HUD 与底部按钮固定不滚动）；竖屏 360×640 与 320×568 均无需滚动。
6. **iOS 硬件静音键**可能同时静音 WebAudio，导致音效无声；这是移动端已知限制，视觉与文字反馈独立完整，不影响玩法与计时。
7. **音效需首次用户手势解锁**（浏览器自动播放策略）：页面加载后未进行任何点击/按键前不会发声；首次点击或按键后自动解锁。
8. **`file://` 下持久化差异**：部分浏览器或隐私模式限制 `localStorage`，此时自动降级为内存态（本次会话内有效）；需要稳定保存最高分时请使用本地静态服务器方式运行。
9. **数据仅存本机**：排行榜与设置保存在当前浏览器 `localStorage`，不跨设备同步、无账号体系（符合规格非范围）。
